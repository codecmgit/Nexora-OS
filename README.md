# 🚀 Nexora OS

> A Modern SaaS-Style Productivity & Finance Dashboard built using HTML, CSS, and JavaScript.

🌐 Nexora OS is a responsive multi-page productivity dashboard designed to help users manage daily workflow, tasks, expenses, notes, and productivity analytics through an interactive and modern user interface.

---

# ✨ Features

## 📋 Task Management
- Add, delete, search, and complete tasks
- Dynamic task updates
- Persistent task storage using LocalStorage

## 💰 Expense Tracker
- Add categorized expenses
- Real-time expense calculation
- Expense management dashboard

## 📝 Notes System
- Auto-saving notes functionality
- Persistent browser storage
- Quick-access personal workspace

## 📊 Analytics Dashboard
- Interactive productivity analytics using Chart.js
- Task completion insights
- Expense statistics visualization

## ⏳ Pomodoro Focus Timer
- Productivity countdown timer
- Start & reset controls
- Focus session tracking

## 🌦️ Weather Integration
- Real-time weather updates using Open Meteo API

## 💡 Daily Motivational Quotes
- Dynamic quote generation using Quotable API

## 🌙 Dark / Light Mode
- Theme switching functionality
- Persistent theme saving

## 🔔 Notification System
- Interactive notifications for user actions

## 📱 Responsive UI
- Mobile-friendly responsive design
- Optimized for desktop, tablet, and mobile devices

## 🎨 Modern UI Design
- Glassmorphism effects
- Smooth animations
- Hover transitions
- Custom scrollbar styling
