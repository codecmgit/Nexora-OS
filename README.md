# Nexora OS

Nexora OS is a modern productivity and finance dashboard built using HTML, CSS, and JavaScript.  
It helps users manage daily tasks, track expenses, save notes, monitor productivity, and stay organized through an interactive multi-page dashboard.

---

## Features

- Task Management System
- Expense Tracker with Categories
- Notes Saving using LocalStorage
- Analytics Dashboard with Charts
- Pomodoro Focus Timer
- Weather Integration
- Daily Motivational Quotes
- Dark / Light Mode
- Notifications System
- Responsive Modern UI
- Glassmorphism Design
- User Login System
- Daily Streak Tracker

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Open Meteo API
- Quotable API
- LocalStorage API
- Font Awesome
